# PILOT Commander v1.1

Correctif du script Scriptable : après avoir choisi « Plus tard », le menu d'activation du retour réapparaît au prochain lancement tant qu'aucun jeton GitHub n'est enregistré. Commandes autorisées limitées à `ping`. Le jeton à permissions fines doit être saisi **sur l'iPhone uniquement**, réservé au seul dépôt FSDFGS, avec Contents read/write et expiration courte.

**Sécurité :** dépôt public, aucun message privé ni profil de rencontre à publier. Le script ne contrôle pas les autres applications et ne s'auto-exécute pas en arrière-plan. Un rapport apparaît sur le téléphone même sans jeton, mais il n'est pas renvoyé à ChatGPT automatiquement.
